# 📋 Task Tracker — Корпоративный трекер задач

Серверное приложение для управления задачами сотрудников. Обеспечивает CRUD операции для сотрудников и задач, отслеживание загруженности и выявление важных задач.

---

## 🚀 Функционал

- ✅ CRUD для сотрудников и задач
- ✅ Назначение исполнителей
- ✅ Родительские и дочерние задачи (зависимости)
- ✅ Статусы задач: backlog → todo → in_progress → review → done
- ✅ Приоритеты: low / medium / high / critical
- ✅ Проекты и теги
- ✅ Комментарии к задачам
- ✅ Учёт рабочего времени
- ✅ История изменений задач
- ✅ Уведомления (Telegram)
- ✅ Специальные эндпоинты:
  - **Занятые сотрудники** — сортировка по количеству активных задач
  - **Важные задачи** — задачи, блокирующие другие, с кандидатами на выполнение
- ✅ JWT-авторизация
- ✅ Пагинация
- ✅ Валидация данных
- ✅ Документация API (Swagger / ReDoc)
- ✅ Docker
- ✅ Тесты (покрытие 75%+)
